# Invictus Team — redesign

Redesign responsivo do site Invictus Team, em React 19, Vite 6 e CSS modularizado.

## Rodar localmente

npm install
npm run dev

## Build

npm run build

## Observações

- Esta implementação está na branch feature/redesign-profissional-react, sem alteração na main.
- Os preços e horários foram preservados do site original e devem ser confirmados pela equipe antes da publicação definitiva.
- As fotos e o logotipo são carregados do repositório público original da própria Invictus (MKTTeus/Invictus).
- O formulário abre o WhatsApp e não armazena dados pessoais.
- Para automatizar previews de branches, conceda ao Vercel acesso ao repositório MKTTeus/Invictus e vincule-o ao projeto na Vercel.
